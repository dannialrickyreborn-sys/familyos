# Roadmap

FamilyOS is built in five milestones. Each milestone must be solid before the next one starts. No detailed tasks are defined ahead of time — each milestone's tasks are scoped when that milestone begins.

## M1 — Foundation

Establish the repository structure, baseline documentation, and working conventions. No application code, workflows, or automation.

**Status: Complete.**

## M2 — First Validated Capability

Introduce the capability model — how FamilyOS proposes, builds, validates, and retires capabilities — and carry one example capability through it.

**Status: Complete.** The capability model is in place (`docs/capabilities/`), and the WhatsApp Foundation (CAP-002) was validated end-to-end on a real device and tagged `v0.2.0`. The application layer above it — Family Registry (CAP-003) and Message Router (CAP-004) — followed.

## M3 — Knowledge

Build a durable, searchable knowledge base for family information and decisions.

## M4 — Growth

Track personal and family development over time.

## M5 — Intelligence

Weave AI assistance directly into the system to surface what matters, when it matters.
